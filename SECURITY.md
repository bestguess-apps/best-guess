# Security

Found a problem? Please report it privately with the "Report a vulnerability" button on this repo's Security tab, not in a public issue.

This app keeps your watchlist and settings on your device and doesn't send them anywhere. It only asks CoinGecko for the latest prices of the coins on your watchlist, and a built-in privacy lock blocks every other site.

Last checked: 2026-11-10 (version 0.2.0, stage 2 plan review and security release check; full release check comes with the first release)
